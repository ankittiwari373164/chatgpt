🔑 Google Drive — Service Account checking…

One-time setup. Create a Service Account in Google Cloud Console → download JSON key → share each client's Drive folder with the service account email (Editor access) → paste the JSON below.
Permanent access — never expires.

📖 Step-by-step setup
1. Go to Google Cloud Console → Credentials
2. Click + Create Credentials → Service Account → give any name → Done
3. Click the service account → Keys tab → Add Key → Create new key → JSON → Download
4. Enable the Drive API for the project
5. Open each client's Google Drive folder → Share with the service account email (in the JSON as client_email) with Editor access
6. Paste the entire downloaded JSON below → Save

📦 Weekly Batch Client: — pick a client above —

Step 1: click Generate Week to build this week's posts for the selected client. The dashboard queues a Tampermonkey prompt per posting day (3 for MWF, 6 for Mon→Sat, 7 for Daily).
Step 2: as each image generates, it's uploaded to the client's Drive folder (filename = topic). Caption + hashtags are saved in the file's Drive description.
Step 3: click 🔄 Regenerate on any image you don't like — it queues a fresh generation and replaces the file in Drive when done.
Step 4: open the Drive folder and review. MetaFlow (separate tool) picks up from here for scheduling to Facebook + Instagram.
